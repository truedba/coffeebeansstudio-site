Supprimer vos données

Koselig, un jeu de Coffee Beans Studio

Dernière mise à jour: 17 novembre 2026

Koselig fonctionne sans compte : il n’y a donc aucun compte à supprimer. Nous ne conservons pas votre progression sur nos serveurs.

Données sur votre appareil

La progression, les sauvegardes, les réglages, l’état de l’achat « Sans pub » et votre choix de consentement publicitaire sont enregistrés sur votre téléphone. Pour tout effacer, supprimez l’application :

  • iPhone : maintenez le doigt sur l’icône de Koselig → Supprimer l’app → Supprimer l’app.
  • Android : maintenez le doigt sur l’icône de Koselig → Infos sur l’appli → Désinstaller (ou Stockage → Vider l’espace de stockage pour garder l’application mais effacer ses données).

Supprimer l’application n’annule pas et ne retire pas l’achat « Sans pub » : il est rattaché à votre identifiant Apple ou à votre compte Google et pourra être restauré plus tard.

Copie iCloud (iPhone)

Sur iPhone, la progression et les sauvegardes sont aussi copiées dans votre propre iCloud. Apple la conserve sous votre identifiant Apple. Pour l’arrêter, désactivez iCloud pour Koselig : Réglages → [votre nom] → iCloud.

Analyse et rapports de plantage

Les événements d’analyse et les rapports de plantage (Google Firebase) ne sont liés ni à votre nom ni à votre e-mail : nous ne pouvons donc pas retrouver les données d’une personne. Ils sont supprimés automatiquement : les événements d’analyse au plus tard après 14 mois, les rapports de plantage après 90 jours.

Données publicitaires

Les publicités de Koselig sont fournies par Google AdMob. Google est responsable du traitement des données qu’il collecte. Vous pouvez :

  • réinitialiser ou supprimer votre identifiant publicitaire Android : Paramètres → Google → Annonces ;
  • modifier votre consentement dans le jeu : Réglages → Publicité et données ;
  • gérer ou supprimer des données dans votre compte Google : Mon Centre publicitaire et Données et confidentialité ;
  • découvrir comment Google utilise les données des applications : policies.google.com.

Vos e-mails

Si vous nous avez écrit et souhaitez que vos messages soient supprimés, envoyez une demande à support [at] coffeebeansstudio [dot] eu depuis la même adresse. Nous les supprimerons sous 30 jours et vous le confirmerons.
